# Changelog

## 0.1.2

- Add an optional mobile long-press menu with Open URL and Copy URL actions.

## 0.1.1

- Add optional display text with `{name|https://example.com}` syntax.

## 0.1.0

- Initial development version.
- Configurable opening and closing delimiters, defaulting to curly braces.
- Configurable routing to a normal browser window, private browser window, system browser, custom launch action, or clipboard.
- Reading View and Live Preview rendering.
- Configurable browser and trailing icon.
