# Contributing

## Local setup

1. Install Node.js 22 and pnpm 11.
2. Run `pnpm install`.
3. Run `pnpm run check` before opening a pull request.

## Testing in Obsidian

Copy `main.js`, `manifest.json`, and `styles.css` into a folder named `link-router` under a test vault's `.obsidian/plugins` directory. Reload Obsidian and enable **Link Router** under Community plugins.

Do not test unreleased builds in a vault without a backup.
